# 🌐 Como Compartilhar a Aplicação

Existem **3 formas** de compartilhar o Convert-to-Holytics:

---

## 🚀 **Opção 1: ngrok (Mais Rápido - Recomendado)**

Compartilhe sua aplicação localmente com **um link público** em segundos!

### **Passo a Passo:**

**1. Baixe o ngrok:**
```
https://ngrok.com/download
```

**2. Extraia e rode:**
```powershell
# Com a aplicação rodando (python run.py)
# Em outro terminal:
.\ngrok.exe http 5000
```

**3. Copie a URL gerada:**
```
Forwarding: https://abc123.ngrok-free.app -> http://localhost:5000
```

**4. Compartilhe** essa URL! 🎉

### **Prós:**
- ✅ Instantâneo (30 segundos)
- ✅ HTTPS grátis
- ✅ Funciona 100%
- ✅ Sem configuração

### **Contras:**
- ⚠️ Precisa manter seu PC ligado
- ⚠️ URL muda cada vez que reiniciar

---

## 📦 **Opção 2: GitHub + Instruções**

Outras pessoas podem **rodar localmente** no computador delas.

### **Compartilhe:**
```
https://github.com/RaphaelSchultz/Convert-to-Holytics
```

### **Instruções para eles:**
```bash
# 1. Clone
git clone https://github.com/RaphaelSchultz/Convert-to-Holytics.git
cd Convert-to-Holytics

# 2. Instale Python 3.9+
# 3. Instale dependências
pip install -r requirements.txt

# 4. Execute
python run.py

# 5. Abra navegador
http://localhost:5000
```

### **Prós:**
- ✅ Cada um roda no próprio PC
- ✅ Sem custos
- ✅ Funciona offline

### **Contras:**
- ⚠️ Requer Python instalado
- ⚠️ Cada usuário precisa configurar

---
