# 🎯 Como Usar o Convert-to-Holytics.exe

## ✅ **O que é:**

Um executável Windows **standalone** que:
- ✅ Roda o servidor Flask
- ✅ Abre o navegador automaticamente  
- ✅ **Não precisa instalar Python ou nada!**
- ✅ Interface web moderna (mesma do `python run.py`)

---

## 📦 **Como Usar:**

### **1. Duplo clique no .exe**
```
Convert-to-Holytics.exe
```

### **2. Aguarde ~3 segundos**
- Console pode abrir rapidamente (vai sumir)
- Navegador abre automaticamente

### **3. Use normalmente!**
- Upload do database.db
- Exportar músicas
- Download ZIP ou individual

---

## 📁 **Compartilhar:**

### **Para distribuir:**
1. Copie apenas o arquivo: `Convert-to-Holytics.exe`
2. Envie para outras pessoas (Google Drive, WhatsApp, email, etc)
3. Elas dão **duplo clique**
4. **Pronto!** Funciona sem instalar nada

### **Tamanho:**
- ~40-50 MB (inclui Python + Flask + tudo)

---

## ⚠️ **Avisos Comuns:**

### **Windows Defender / Antivírus:**
- Pode dar **aviso falso** (normal com PyInstaller)
- Adicione exceção ou clique "Executar mesmo assim"

### **"Este app pode prejudicar seu PC":**
- **É SEGURO!** É só o Windows sendo cauteloso
- Clique "Mais informações" → "Executar mesmo assim"

---

## 🔧 **Fechar a Aplicação:**

1. **Feche a aba do navegador**
2. **No console** (se aparecer): Pressione `Ctrl+C`
3. Ou abra Gerenciador de Tarefas → Finalizar "Convert-to-Holytics.exe"

---
